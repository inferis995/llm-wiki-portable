## LLM Wiki Method (metodo Karpathy)

**Tesi**: usare un LLM come compilatore di una knowledge base in markdown è più pratico, economico e flessibile di qualsiasi sistema RAG con vector DB.

## Principi Core
1. **Distillazione** — le pagine diventano più precise nel tempo, mai più lunghe
2. **Opinionata** — prendi posizione, non aggregare neutralmente
3. **Zero note grezze** — ogni file in wiki/ è già distillato
4. **Wikilinks** — la struttura emerge dai `[[link]]`

## Confronto con RAG
- RAG: embedding + vector search + retrieval in tempo reale
- LLM Wiki: lettura diretta dei file + contesto ampio — più semplice, zero infrastruttura
